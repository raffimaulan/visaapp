# 🛂 VisaApp — Visa Management System

VisaApp adalah aplikasi berbasis web untuk mengelola proses pengajuan visa secara digital, mulai dari data pemohon, aplikasi visa, pembayaran, dokumen, hingga laporan administrasi.

Project ini dibuat menggunakan PHP Native dan MySQL dengan tampilan dashboard modern serta sistem pengelolaan data yang terstruktur.

---

# ✨ Features

## 📊 Dashboard System
- Dashboard statistik aplikasi visa
- Monitoring total pembayaran
- Tracking status pengajuan
- Ringkasan data realtime

---

## 👥 Applicant Management
- Tambah data pemohon
- Edit & hapus data pemohon
- Penyimpanan nomor passport
- Search applicant data

---

## 🛂 Visa Application Management
- Create visa application
- Update application status
- Visa process tracking
- Relasi applicant & application

---

## 💳 Payment Management
- DP & full payment system
- Payment history
- Payment status tracking
- Transaction management

---

## 📁 Document Management
- Upload dokumen persyaratan
- File validation system
- Preview & download file
- Secure file storage

---

## 📑 Reporting System
- Export PDF report
- Export Excel report
- Payment report
- Visa application report

---

## 🔐 Authentication & Security
- Login authentication
- Session management

- Form validation
- File upload validation

# 🚀 Installation

## 1️⃣ Clone Repository

```bash id="zcr0fj"
git clone https://github.com/raffimaulan/visaapp.git
```

---

## 2️⃣ Move Project

Pindahkan folder project ke:

* `htdocs` untuk XAMPP
* `www` untuk Laragon

---

## 3️⃣ Import Database

* Buka phpMyAdmin
* Buat database baru
* Import file SQL dari folder:

```bash id="7wkgur"
Database/
```

---

## 4️⃣ Configure Database

Atur koneksi database pada file:

```bash id="qk3f5i"
helper/connection.php
```

---

## 5️⃣ Run Application

```bash id="7nnjlwm"
http://localhost/visaapp
```
